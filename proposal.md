# 3D Background with Parallax Scrolling 

## Repository
https://github.com/Madi7777/3DParallax.git

## Description
This will create a code that you can apply to any 2D background that will create a scolling parallax effect. This can be used in side-scroller games, platformers, or for personal/professional projects that you would want to enhance with a 2D background that looks 3D. 

## Features
- Layer Depth 
	- The background will have 4-5 drawings layers ontop of eachother. Each increasing in detail as you get closer to the camera. Each layer will also be a different color. Lighter and less saturated the further back you got and darker and more saturated the closer you are. 
- Camera Scroll
	- When you scroll left or right, each layer will scroll individually which creates a parallax effect. The background images will scroll slower than the foreground images.This will give the background a 3D effect.
- 2D Drawn Images  
	- Each layer will need to be hand drawn and then imported into VSCode. Keeping in mind the rules and requires for an effective background, midground, and foreground. 

## Challenges
- Keeping the speeds of each layer different to create the paralax effect
- Setting up the game loop and determining game variables such as FPS, resolution, screen width/height, etc.
